# Existing Website Update & Responsive Fix

Self-initiated portfolio project for TomurcuKids.

## Brief
Update an existing responsive landing page without rebuilding the whole site.

## Tasks completed
- Added 4 new content sections while preserving the existing visual direction.
- Fixed an unstable floating animation by reducing transform distance and using a smoother transform-only animation.
- Improved responsive behavior for mobile.
- Added clear navigation anchors.
- Kept the project lightweight: plain HTML + CSS, no framework required.

## Files
- `before.html` — simplified original page with the animation issue.
- `after.html` — updated responsive page with four added sections and corrected animation.

## Portfolio positioning
This project demonstrates small website updates, responsive layout work, CSS troubleshooting and careful implementation of an existing design direction.
